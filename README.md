# 🕹️ GamesSells

Aplicación web desarrollada con **Django** para la gestión y venta de videojuegos.  
Incluye un sistema completo de **autenticación, roles, carrito de compras, CRUD de productos y panel de administración**.  
Además, expone una **API pública** para consultar ofertas y cuenta con **base de datos configurada para OracleCL**, lo que la hace fácilmente adaptable a otros motores SQL.

---

## ✨ Funcionalidades principales

- ✅ Registro e inicio de sesión con manejo de roles (cliente / administrador)
- ✅ Gestión de productos con CRUD para videojuegos
- ✅ Carrito de compras funcional
- ✅ Panel de administración personalizado
- ✅ API para exponer ofertas y productos destacados
- ✅ Integración con base de datos OracleCL (configurable)
